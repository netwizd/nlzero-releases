# Установка nlzero 8.2.0

Архив содержит установщик и подписанные пакеты ядра и агента. Он устанавливает
управляющий сервер; ноды затем добавляются через Web-интерфейс.

## Перед установкой

- Чистый сервер **Ubuntu Server 26.04 LTS amd64**, доступ по SSH и права root
  или sudo; запускать установщик нужно в интерактивном терминале.
- Два разных DNS-имени в нижнем регистре: для Web и подключения нод. Их
  DNS-записи должны указывать на адрес устанавливаемого сервера.
- Доступ к TCP 443 со стороны пользователей и нод, а также доступ к
  репозиториям Ubuntu для установки системных пакетов через apt. Пакеты nlzero
  уже находятся в архиве; полностью автономная установка ОС не предусмотрена.
- На выбор: временный самоподписанный TLS-сертификат или действующий
  PEM-сертификат/fullchain с соответствующим незашифрованным PEM-ключом.
  Сертификат должен покрывать оба DNS-имени. Для публичного HTTPS передайте
  полную цепочку `leaf → intermediate(s)`: одного основного сертификата
  недостаточно для проверки HTTPS с чистой ноды.

Перед очисткой действующих серверов сохраните вне них проверенную резервную
копию, средства восстановления, ключи подписи и лицензирования. Сначала
проверьте установку на отдельном чистом сервере. Удаление данных необратимо.

## Проверка и установка

Получите архив и соседний файл `.sha256` от доверенного издателя. В каталоге
с обоими файлами сначала проверьте архив:

```bash
sha256sum --check nlzero-8.2.0-linux-amd64.tar.gz.sha256
```

Должен появиться результат `OK`; при несовпадении остановитесь. Только после
успешной проверки распакуйте и проверьте комплект:

```bash
tar -xzf nlzero-8.2.0-linux-amd64.tar.gz
cd nlzero-8.2.0
./install.sh verify
```

Команда `verify` проверяет комплектность, контрольные суммы и подписи обоих
пакетов без root, sudo и изменения сервера. Не изменяйте скрытый каталог
`.payload`: в нём находятся пакеты и данные проверки.

Программа предоставляется «как есть». До установки прочитайте условия:

```bash
./install.sh license
```

Подробности редакций Free / Unlimited и состояние лицензии доступны после
установки в разделе «Платформа → Лицензия». Уведомления и лицензии сторонних
компонентов находятся в `.payload/THIRD_PARTY_NOTICES.md`.

После успешной проверки запустите первичную установку без аргументов:

```bash
./install.sh
```

Та же команда явно:

```bash
./install.sh install
```

Укажите DNS-имена, данные первого администратора и вариант TLS, затем
подтвердите установку. Пароль администратора — не менее 12 символов.
Установщик подготовит PostgreSQL и сервисы, создаст администратора, включит
HTTPS и загрузит встроенные пакеты в каталог релизов. Существующая политика
входа по SSH сохраняется; перед включением UFW разрешаются фактические порты SSH.

После сообщения о завершении откройте `https://ВАШЕ_ADMIN_ИМЯ/admin/` и войдите
с заданными данными. При временном сертификате браузер предупредит о доверии;
замените его действующим сертификатом в разделе «Платформа». Проверьте вход
по SSH в новой сессии до закрытия текущей. Ноды на чистой Ubuntu 24.04 или
26.04 LTS amd64 добавляются через Web.

Если установка остановилась после изменения сервера, сохраните сообщение
об этапе и причину ошибки. Повторная установка поверх частичного состояния
не поддерживается: сначала устраните причину и восстановите чистый сервер.

## Полное удаление

В согласованное окно обслуживания, после проверки внешней копии, выполните:

```bash
./install.sh uninstall
```

Введите `УДАЛИТЬ` только после проверки резервной копии. Команда удаляет
сервисы nlzero, базу данных, системные ключи и локальные резервные копии.
Системные пакеты Ubuntu сохраняются. Для возврата данных потребуется
восстановление из внешней копии; повторная установка создаёт новую систему.
Чистая установка начинает работу в редакции Free с новым installation ID.
Для Unlimited потребуется лицензия, выпущенная для этой новой установки.

## Первая настройка в Web

После установки войдите под созданным оператором и откройте
**Настройки → Мастер Конфигурации**. Мастер проводит проверку ядра, подключение сервера,
подготовку доступа, запуск VPN и выдачу клиентского профиля. Для новой системы
ссылка на него также появляется на главной странице.

Подготовьте адрес чистого сервера Ubuntu, SSH-доступ и DNS-имя для VPN.
Для первого подключения WireGuard TLS-сертификат VPN не нужен; DNS-имя нужно
направить на адрес выбранного сервера. Мастер показывает требуемую запись.
Наличие профиля подтверждает серверную подготовку; подключение устройства и
доступ в интернет проверяются отдельно.
