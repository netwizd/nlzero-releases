# nlzero — официальные сборки

nlzero — система NLGate для централизованного управления корпоративным
VPN-доступом. Этот репозиторий предназначен для готовых дистрибутивов,
инструкций и примечаний к выпускам. Исходный код продукта хранится отдельно
в закрытом корпоративном Git.

## Скачать и установить

Готовые дистрибутивы публикуются в [Releases](https://github.com/netwizd/nlzero-releases/releases).
Если список выпусков пуст, публичная сборка ещё не опубликована.

1. Откройте нужный выпуск и ознакомьтесь с его требованиями и примечаниями.
2. Скачайте архив `nlzero-VERSION-linux-amd64.tar.gz` и соседний файл `.sha256`.
   Доступ к корпоративному Git для скачивания и установки не требуется.
3. Проверьте SHA-256 командой `sha256sum --check ИМЯ_СКАЧАННОГО_ФАЙЛА.sha256`.
   Продолжайте только при результате `OK`.
4. Распакуйте архив, откройте включённую инструкцию `HOW_TO_INSTALL.md`
   и выполните из каталога дистрибутива `./install.sh verify`.
   Эта команда проверяет комплект и подписи пакетов без установки и без root.
5. После успешной проверки выполните `./install.sh` и следуйте мастеру.

Текущий установщик управляющего сервера рассчитан на чистую **Ubuntu Server
26.04 LTS amd64** с правами root или sudo и интерактивным терминалом.
Потребуются два разных DNS-имени для панели и подключения нод, TLS-сертификат
либо временный самоподписанный сертификат и доступ к репозиториям Ubuntu.
Точные требования и порядок установки указаны в инструкции конкретного выпуска.
Установка нод выполняется отдельно через Web-интерфейс управляющего сервера.

При несовпадении контрольной суммы или ошибке проверки подписи остановитесь
и получите проверенный дистрибутив. Для обновления работающей системы следуйте
примечаниям к выпуску; первичный установщик предназначен для чистого сервера.

## Редакции и лицензирование

| Возможность | Free | Unlimited |
| --- | --- | --- |
| Активные клиенты | До 5 | Без количественного лицензионного ограничения |
| Устройства | До 1 на клиента, до 5 суммарно | Без количественного лицензионного ограничения |
| Группы доступа, ноды и инстансы | Без количественного лицензионного ограничения | Без количественного лицензионного ограничения |
| Активация | Встроена, регистрация и сертификат не требуются | Подписанный сертификат для конкретной установки на ограниченный срок |

Unlimited приобретается у NLGate. Срок и стоимость определяются условиями
поставки. По истечении корректной Unlimited установка переходит в Free;
работающая runtime-конфигурация и данные сохраняются, новые клиенты и устройства
подчиняются квотам Free. Отдельного бессрочного режима нет.

Правообладатель nlzero — **NLGate**. Free является бесплатной редакцией продукта
с закрытым исходным кодом. Условия использования конкретной сборки определяются
сопровождающим её лицензионным соглашением. Сторонние компоненты сохраняют свои
лицензии и уведомления об авторских правах.
