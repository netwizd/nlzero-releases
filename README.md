# nlzero — официальные сборки

nlzero — система централизованного управления корпоративным VPN-доступом,
Telegram MTProto и защищённым DNS. Здесь публикуются готовые дистрибутивы,
инструкции и примечания к выпускам. Исходники собственных компонентов хранятся
в закрытом корпоративном Git.

## Скачать и установить

Текущий выпуск — [8.2.1](https://github.com/netwizd/nlzero-releases/releases/tag/8.2.1).
[Все выпуски](https://github.com/netwizd/nlzero-releases/releases).
[Инструкция по установке и обновлению](HOW_TO_INSTALL.md).

1. Скачайте `nlzero-VERSION-linux-amd64.tar.gz` и соседний `.sha256` из нужного выпуска.
2. Проверьте SHA-256: `sha256sum --check ИМЯ_АРХИВА.sha256`. Продолжайте только при результате `OK`.
3. Распакуйте архив, откройте включённый `HOW_TO_INSTALL.md`, выполните `./install.sh verify`.
4. Для первичной установки выполните `./install.sh` и следуйте мастеру.

Управляющий сервер устанавливается на чистую **Ubuntu Server 26.04 LTS amd64**.
Нужны root или sudo, терминал, два DNS-имени для панели и подключения нод,
TLS-сертификат либо временный самоподписанный сертификат и доступ к репозиториям
Ubuntu. Ноды добавляются отдельно через веб-интерфейс. Доступ к корпоративному
Git или учётная запись GitHub для скачивания и установки не нужны.

Для обновления с 8.2.0 скачайте `update.sh` и `update.sh.sha256` из выпуска
8.2.1, проверьте SHA-256 и просмотрите скрипт. После подготовки backup по
инструкции выполните `sudo bash ./update.sh --check`, затем `sudo bash ./update.sh`.
Скрипт скачает последний стабильный выпуск и проверит подписи существующими
ключами доверия. При отсутствии новой версии система не меняется.
Также доступно `sudo ./install.sh update` из распакованного нового комплекта.
Оба способа сохраняют настройки и данные. Подписанные манифесты и архивы core/agent
для каталога релизов опубликованы отдельно; после импорта пакетов агенты
обновляются штатным развёртыванием из Web.

При несовпадении контрольной суммы или ошибке подписи остановитесь и получите
проверенный дистрибутив.

## Лицензирование

Программа предоставляется **«как есть»**. Установка и использование готовых сборок
разрешены в пределах выбранной редакции. Подробности Free / Unlimited и состояние
лицензии доступны в приложении: **«Платформа → Лицензия»**. Публичное скачивание
сборки не предоставляет Unlimited.

[Условия использования](LICENSE.ru.md) включены в дистрибутив; до установки их можно
прочитать командой `./install.sh license`. Исходники собственных компонентов
закрыты. Сторонние компоненты сохраняют свои лицензии и уведомления; необходимые
соответствующие исходники прилагаются к выпускам отдельно.
